# Ktor Kotlin framework

Builds the current [Ktor](https://github.com/ktorio/ktor) source with JDK 17.
Ktor is Kotlin's asynchronous HTTP server and client framework. The Gradle
assemble build compiles its multi-module implementation and checks that the
generated JVM server-core artifact is available. Browser-only tests are not
part of this Linux source-compilation validation.
